# 飼養知識庫 — 寫作範本說明

這個資料夾放你自己寫的品種飼養指南，`ingest_knowledge.py` 會把這裡的 `.md` 檔
切成一段一段的知識片段（chunk），算好語意向量，存進 Chroma，讓 `/chat` 在客人問
飼養相關問題時可以抓到你寫的真實內容，而不是只靠 LLM 自己的通用知識。

## 格式規則（照著這個寫，腳本才認得出來）

每個品種一個檔案，檔案開頭要有這段 YAML frontmatter（species 要跟資料庫裡
`Product.species` 的值完全一樣，之後才能依品種過濾）：

```markdown
---
species: 豹紋守宮
---

# 豹紋守宮 飼養指南

## 溫濕度

這裡寫這個主題的內容...

## 餵食

這裡寫這個主題的內容...
```

- 每個 `##` 標題底下的內容會被切成一個獨立的 chunk，標題文字本身會存成這個
  chunk 的 topic metadata（例如「溫濕度」）。
- 不用擔心段落太短或太長——腳本會依內容長度自動決定要不要再細切，你只要
  專心把內容寫對、寫清楚就好。
- 目前先寫 4 個主題就好：**溫濕度**、**餵食**、**飼養箱佈置**、**挑選健康個體**。
  其他像品系/基因、疾病這種進階主題，先讓 LLM 用自己的知識頂著，之後有空再補。
- 寫完一個品種，馬上可以跑 `python ingest_knowledge.py` 重新索引，再跑
  `python eval_rag.py` 看抓得準不準。
